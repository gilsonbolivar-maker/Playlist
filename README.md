# Playlist da Fernanda

PWA para a Fernanda escolher as músicas que quer baixadas e enviar a lista pelo WhatsApp.

- `index.html` — app (catálogo, busca, filtros, pedidos extras, recado, envio)
- `sw.js` — cache offline (mude `CACHE` a cada atualização)
- `manifest.webmanifest` + `icons/` — instalação na tela inicial

Deploy: Netlify, publicando a raiz (`netlify.toml`).
